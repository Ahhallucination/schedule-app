## 排班管家（schedule-app）正式版开发
位置：/Users/zousonglin/Desktop/workbuddy/schedule-app

按 `需求.txt`（四十二章需求文档）完成了完整正式版智能排班管理软件：

- **技术栈**：Vite + React 18 + TypeScript + Tailwind v3，exceljs（懒加载）做 Excel 导入导出，无其他重型依赖。
- **排班引擎**（src/engine/，与 UI 完全解耦）：
  - 确定性算法（非随机、非AI）：可行性检测（每日二部图最大匹配 + 人力池 + 全局容量）→ 多起点贪心构造（稀缺度/晚班优先两种顺序，含夜班连班 blocking 启发式）→ 局部搜索优化（5类移动：补员/同日转移/同日换班/周末↔工作日换日/跨日交换，时间预算+取消+进度）→ 评分与统计。
  - 硬约束：人力需求、日期级规则（必须休息/上班/指定班次/禁止班次）、连续工作上限、按班次的连续上限（如连续夜班≤3）、班次间休息时间（按实际时间含跨天）、硬性出勤目标范围。
  - 软约束：班次公平/出勤均衡/周末公平/员工偏好/避免长连班，权重1-5可配。
  - 无解诊断：具体原因 + 修改建议（如"夜班需6人仅5人可用，建议调需求至5人"）；规则互斥检测。
- **测试**：test/engine.test.ts（55项）+ test/excel.test.ts（14项）全部通过。100人×31天×5班次约2秒，评分99。
- **UI**：左侧导航9页（总览/项目/员工/班次/人力需求/规则/排班结果/统计/设置），现代SaaS风格；总表默认显示+班次独立视图、粘性姓名列/表头、单元格弹层编辑+排班解释、锁定+重优化、实时冲突检查、撤销/重做、⌘S/⌘Z/⌘F 快捷键、空状态、粘贴导入名单、Excel/CSV导入、多Sheet格式化Excel导出、localStorage自动保存、项目JSON备份。
- **已知取舍**：极端紧凑场景（如10人×80%利用率×跨天夜班×12h休息）属于结构化极难实例，系统诚实报告冲突（符合需求第十五章）而非假成功。
